Whoami-Labs es una plataforma educativa 100% gratuita, que proporciona laboratorios dockerizados para el aprendizaje de hacking ético y pentesting. Ahí podemos encontrar:

* Laboratorios descargables (Docker/OVA) con vulnerabilidades simuladas
* Sistema de puntuación, ranking y perfiles públicos
* Comunidad de aprendizaje de seguridad informática
* Recursos educativos gratuitos y Mentor IA de apoyo

https://whoami-labs.com/

En este repositorio ire subiendo mis writeups de dichos laboratorios.
